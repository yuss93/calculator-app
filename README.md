# Calculator App

A running-total calculator built with React and Vite. Enter a number, choose
an operation, and it applies to the accumulated result.

## Features

- Addition, subtraction, multiplication and division against a running total
- Division guarded against divide-by-zero, results rounded to two decimals
- Separate resets for the result and the input field
- State managed with `useState`, inputs fully controlled

## Running locally

```bash
npm install
npm run dev
```
